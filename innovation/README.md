# 의대교육혁신사업 결과

https://medahn-cmd.github.io/innovation/

교육과정·학습지원·평가 3개 축, 15개 과제, 15개 보고서, 109개 세부 성과를 연결합니다.

지역사회기반 교육과정의 4개 운영 모형·9개 점검 영역·18건 사례 조사 결과를 추가했습니다. 참여 대학 수는 초안의 집계와 목록이 달라 확인 중으로 표시합니다.

과제별 주요 결과를 그래프, 비교표, 단계도, 산출물 구성도로 제공합니다. 수치는 1차년도 보고 시점 기준이며, 개발·계획·시범운영의 상태를 구분합니다. 원본 파일과 예산·집행 내역, 개인 연락처는 공개하지 않습니다.

## 파일 구성

index.html, results.css, results-data.js, results-community.js, results-visuals.js, results-app.js, assets--campus.png가 현재 사이트를 구성합니다. 데이터 → 지역사회 추가 데이터 → 시각화 → 화면 앱 순서로 불러옵니다.

과제 주소: #/project/과제ID
상세 주소: #/project/과제ID/record/번호

이전 projects--project-XX 파일들은 자료 입력 전의 초기 페이지이며 현재 메뉴에서 사용하지 않습니다.
