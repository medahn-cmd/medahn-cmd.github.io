# 의대교육혁신사업 결과

https://medahn-cmd.github.io/innovation/

세부 추진계획의 교육과정·학습지원·평가 3개 축을 중심으로 15개 과제를 연결하고, 제공된 14개 최종보고서의 핵심 결과와 101개 상세 기록을 정리한 웹사이트입니다.

## 사용

- 사업 지도 → 과제 개요 → 보고서 상세 기록으로 이동합니다.
- 성과 탐색에서 분야 필터와 보고서 본문 검색을 이용할 수 있습니다.
- 상세 기록에서 인쇄 / PDF 저장을 지원합니다.
- 과제별 주소는 `#/project/과제ID`, 상세 기록은 `#/project/과제ID/record/번호`입니다. 주소를 그대로 복사해 공유할 수 있습니다.

## 파일

- index.html: 웹페이지 시작점
- results.css: 화면·모바일·인쇄 스타일
- results-app.js: 과제 탐색 및 상세 화면
- results-data.js: 공개용으로 정리한 과제별 결과
- assets--campus.png: 캠퍼스 일러스트

예산·집행 내역, 개인 연락처와 원본 보고서 파일은 공개 자료에 포함하지 않았습니다. 상세 기록은 원문 본문·표를 재구성한 발췌본이며, 별도 첨부 산출물이나 원본 도판 전체를 포함하지 않습니다. 지역사회기반 교육과정은 별도 결과보고서 미제공으로 표시했습니다. 수치와 완료 상태는 각 보고서 작성 시점 기준입니다.

기존 `projects--project-XX` 파일들은 자료 제공 전의 초기 페이지입니다. 현재 사이트의 탐색은 위 새 주소 체계를 사용합니다.
